# Training Atlas

Public React/Recharts fitness micro-app for robertmuse6 GitHub Pages. The user expressly approved publishing his fitness records in this public repository on Sep 27 2026. `public/data.json` is the accumulating source of truth for the app; it contains only user-reported facts. One dated row per workout or morning check-in, with null for unreported values. Update it with new check-in data after the user reports it. Do not infer soreness, energy, sleep quality or pace gains. A separately held private Google Sheet is a backup but is not connected to the public app.

`npm install && npm run build` produces `dist/`, ready to publish via GitHub Pages. `vite.config.ts` uses relative assets so the site works at a repository subpath. On opening, it fetches public `data.json` without caching. The 7/28-day controls and interactive Recharts plots use only these records. “Preview sample” switches to clearly illustrative sleep, energy and soreness; “✕ Back to real data” restores the actual ledger without reloading. The CSV import permits viewing the Sheet locally without transmission or storage.

Schema: `{date:"YYYY-MM-DD",type:"workout|morning",sleep:number|null,energy:number|null,soreness:number|null,workout:string,minutes:number|null,distance:number|null,incline:number|null}`. Missing values are null. The public repository includes only data the user has authorized for public disclosure, never tokens or credentials.
